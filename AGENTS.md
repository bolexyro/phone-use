# Phone Control & DHD

Whenever you're done with a change to the android app, build and install it to the connected device using adb.

## Commit messages

Use Conventional Commits for new commits:

```text
<type>(<scope>): <imperative description>
```

Use a lowercase type and scope with a concise imperative subject. Prefer
`feat`, `fix`, `docs`, `refactor`, `test`, or `chore` as the type. For example:

```text
docs(dhd): document deferred density comparison
```
